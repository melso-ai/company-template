# Company documents

Use this folder for context shared across Areas. Begin with [company.md](company.md), then describe the [product](product.md), [competitors and alternatives](competitors.md), and [strategy](strategy.md).

These documents are blank prompts. Replace them with facts, decisions, sources, and open questions as you learn. Keep Area-specific detail in that Area's `docs/` folder and link to it rather than copying conflicting versions.

Use Markdown or other supported text files. Upload binary media as Melso attachments. Never put credentials in this folder.
