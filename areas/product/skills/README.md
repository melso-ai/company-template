# Product skills

Skills here are available when a Task starts in the Product Area. Use root [skills/](../../../skills/README.md) for a procedure that should be available in every Area.

Create a readable folder such as `product-review/` containing `SKILL.md`. This complete example is documentation only:

```markdown
---
name: Product review
description: Review the requested Product documents and summarize facts, decisions, and open questions.
---

# Product review

Read the documents relevant to the Task. Summarize their key facts,
decisions, and open questions, with links to the sources. Identify
assumptions and missing information. Save a review only when requested.
```

Supporting references and optional scripts belong inside that skill's directory. Follow the [global skills guide](../../../skills/README.md) for structure and scope. A skill's instructions do not grant new account permissions.
