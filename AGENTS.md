# Company instructions

Use this repository as the company's shared instructions, documents, and operating definitions. Start with the Task's objective, the relevant Area instructions, and the documents needed for the work.

Keep facts, assumptions, and open questions distinguishable. Link to the sources that support decisions and record meaningful changes in the relevant document. The starter documents contain prompts, not facts about this company.

Use the connections and permissions available to the current execution. Repository instructions do not grant access to accounts or authorize unrelated actions. Keep credentials, private keys, and authentication material out of Git.

Make focused changes, preserve other people's work, and review the diff before committing. Validate configuration changes and check that a pushed revision becomes active before describing it as live. Report the result, its supporting evidence, and any remaining blocker.
